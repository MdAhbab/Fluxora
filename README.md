# Fluxora

![Fluxora animated project banner](docs/fluxora-banner.svg)

Fluxora is a building management SaaS platform created by **Ahbab**. It brings apartment finance, visitor security, maintenance, resident communication, documents, bookings, parking, assets, and building analytics into one operating dashboard.

## What Fluxora Includes

| Area | Capabilities |
| --- | --- |
| Finance | Invoices, payments, monthly service charges, utility bills, expenses, and reporting |
| Security | Visitor QR scans, intercom logs, gate events, SOS incidents, lift status, and emergency contacts |
| Resident Operations | Notice board, resident directory, polls, documents, events, and group chat |
| Facilities | Shared resource bookings, units and occupancy, parking layout, vehicles, access cards |
| Maintenance | Tickets, staff attendance, assets, warranties, vendor lookup, and service provider reviews |

## Tech Stack

- **Frontend:** React 19, Vite, React Router
- **Backend:** Django 5, Django REST Framework, token authentication
- **Database:** MySQL
- **Optional services:** Celery, Redis, Channels, S3 storage, email/SMS providers

## Project Structure

```text
backend/
  fluxora/            # Main Django app: models, views, URLs, seed command
  fluxora_saas/       # Required Django project settings/ASGI/WSGI/Celery package
  manage.py
frontend/
  src/                # React app pages, components, styles, API client
docs/
  fluxora-banner.svg  # GitHub-compatible animated README banner
```

`backend/staticfiles/` is generated by Django `collectstatic` and is intentionally not committed.

## Setup

### 1. Backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install django djangorestframework mysqlclient celery channels
```

Set MySQL environment variables if your local values differ:

```bash
export MYSQL_DATABASE=fluxora
export MYSQL_USER=root
export MYSQL_PASSWORD=12345678
export MYSQL_HOST=127.0.0.1
export MYSQL_PORT=3306
```

Run migrations and seed the Bangladeshi demo workspace:

```bash
python manage.py migrate
python manage.py seed_demo_data
python manage.py runserver 127.0.0.1:8000
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Open:

```text
http://127.0.0.1:5173/
```

The Vite dev server proxies `/api` requests to `http://127.0.0.1:8000`.

## Notes

- Run `seed_demo_data` any time you need fresh demo content. It is idempotent and updates existing demo records.
- The dashboard uses live Django API data through token authentication.
- Signup creates a new Fluxora workspace and stores selected modules, including Units & Occupancy, Assets & Compliance, and Parking & Access.
